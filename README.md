# aquilaoliveira.com

Site do portfólio de Áquila Oliveira — Diretor Audiovisual · Artista Visual · Gestor de Operações Criativas.

Site estático (HTML, CSS e JavaScript), sem etapa de build. Publicado pela Netlify.

- `index.html` — layout, textos PT/EN e animações.
- `images/` — fotos.
- `js/projetos.js` — **os 51 projetos**, categorias, faixa "Em cena", trajetória e clientes. Para adicionar vídeo, coloque o ID do YouTube no campo `video` do projeto.

Para ver localmente: abra o `index.html` no navegador.
